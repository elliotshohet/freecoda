# Freecoda

Privacy-focused local coding agent and account website. This repository is private during development.

## Website

```sh
bun install
bun run dev
```

Open http://127.0.0.1:3010. The website reports actual service configuration; unavailable integrations are disabled. No example account balances or fake activity are served.

## Status

The landing page, pricing, documentation, privacy, device approval, and workspace interfaces are implemented. The CLI, transactional usage accounting, device authorization, and payment backend are in active implementation. Hosted inference remains disabled until the model evaluation and privacy checks pass.
